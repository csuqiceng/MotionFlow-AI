# 临时位置生命周期设计

## 目标

临时对话、AI 规划、流程预览和未保存草稿不得把坐标写入持久位置库。仅当用户明确保存位置、命令或流程时，才允许持久化正式引用。

## 清理策略

1. 清理前生成位置库备份和候选清单。
2. 识别 `flowdraft:*`、`agent:*`、`ai_first:*` 等临时命名位置。
3. 扫描已发布命令与流程的引用；被引用的位置不删除。
4. 保留系统固定位置和人工保存位置。
5. 删除未引用的临时位置，并记录审计结果与可恢复备份路径。

## 运行时行为

临时动作传递内存中的坐标或临时 ID，不调用位置注册持久化接口。保存命令、流程或位置时才创建正式注册项。临时 ID 不进入位置库列表。

## 验收

- 临时对话后位置总数不增加。
- 保存命令/流程后，正式引用仍可解析。
- 清理后不保留未引用的临时前缀位置。
- 备份可恢复清理前状态。
