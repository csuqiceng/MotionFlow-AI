C. 小步美化现有抽屉

风险最低，但参考页里的“操作态势感”和底部安全控制很难完整表达，更像补丁。

建议落地范围

第一阶段
  • 新增机器人工作区布局：左状态、中对话、右场景。
  • 复用现有 robot API，不改后端契约。
  • 把 dry-run 结果改为运动计划确认卡片。
  • 底部固定安全控制条，明确硬件急停优先。
第二阶段
  • 补齐实时状态轮询或 WebSocket 推送。
  • 执行流程时间线替代原始 JSON 日志。
  • 报警场景、记忆审核、流程草稿单独组件化。
  • 需要现场大屏时，再升级为独立 /operator 路由。
