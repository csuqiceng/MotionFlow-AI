# 机器人安全按钮的非阻塞 Tip 交互

## 目标

移除右侧机器人面板中急停、解除急停、暂停、继续、报警复位、解除取消和停止当前按钮的两层浏览器确认弹框。用户点击后只显示非阻塞 Tip。

## 行为

所有七个按钮继续复用同一条既有安全调用链：生成系统动作计划、提交工作区与急停就绪确认、取得服务端确认码并执行。前端不再调用 `window.confirm`。

点击后立即显示“正在执行{动作}…”，请求完成后替换为“{动作}已执行”或“{动作}失败：{原因}”。请求进行时保留现有禁用全部安全按钮的行为，防止重复提交。

## 安全边界

本改动只替换浏览器弹框。不会删除服务端安全计划、会话绑定、确认码、默认 dry-run、后端能力校验或独立急停路径。

## 验收

- 七个按钮均不再出现浏览器确认弹框。
- 每个按钮显示执行中与成功/失败 Tip。
- 仍通过同一个 `robotSystemAction` 的计划、确认和执行调用链。
- 组件测试覆盖无弹框、执行中 Tip 与成功/失败 Tip。
